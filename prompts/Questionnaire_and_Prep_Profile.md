# Before We Build: Where Our Client History Lives + My Meeting Prep

Agent Workshop · Nov 10, 2026

Every agent we build today is only as good as what it can read. Part A finds out where our client history lives (we answer it once, together). Part B makes each person's Meeting Prep agent fit the way they work (each person answers it on their own). Part C is a prompt you can paste into Claude so it asks you the Part B questions and writes your profile for you.

---

## Part A · Where does our client history live? (team, ~15 minutes)

For each row, answer four things:
- **Where** is it today?
- **Whose account** is it in?
- **How organized** is it? (1 = scattered, 5 = one place, same naming)
- **Can the AI read it?** Yes / Only the assigned coach / No

| # | What | Questions |
|---|---|---|
| A1 | **Past client meeting notes** | Where do session and call notes live: Google Docs, Google Drive, OneDrive, ClickUp Docs, a notebook app, or paper? One doc per client or one per session? How far back do they go? |
| A2 | **Meeting recordings and transcripts** | Do you record Zoom calls? Cloud or on your computer? Which Zoom plan? Who is usually the host? Do you use a note-taker (Zoom AI Companion, Fathom, Otter, Fireflies)? |
| A3 | **Email** | Do clients write to your own address, to a shared inbox (like info@), or both? Who reads the shared inbox? |
| A4 | **Phone calls and texts** | Do client calls happen on your cell, the GHL phone, Zoom, or WhatsApp? Are any calls recorded? Do you text clients? |
| A5 | **CRM and pipeline** | What lives in GoHighLevel and what lives in ClickUp? When a prospect signs, what happens to their record? If the two disagree, which one is right? |
| A6 | **Tasks and commitments** | Do action items from calls go into ClickUp? Who creates them, and when? |
| A7 | **Client documents** | Proposals, contracts, assessments (360s, profiles), workbooks: where are they? Is there one folder per client, named the same way as in ClickUp and GHL? |
| A8 | **Client experience data** | Where are CSAT scores, session bookings and attendance? Which tool books sessions? |
| A9 | **Research about clients** | Do you keep notes on a client's company, industry news, promotions or LinkedIn changes anywhere? |
| A10 | **Calendar** | Are all client meetings on Google Calendar with the client's real email on the invite? Are any booked through GHL or another booking link? |
| A11 | **Anything else** | Slack or WhatsApp groups, voice memos, handwritten notebooks, shared spreadsheets? |

**Three more questions for the team**
1. Which **5 clients** matter most right now? We set those up first.
2. How far back should the agents look? (Suggested: 90 days.)
3. What must the AI **never** read? (For example: personal health details, HR investigations, a specific client.)

### B2. What matters most to me in a brief
Rank the top 3 (1 = most important) and cross out the 3 you never want to see.

| Item | Top 3 | Never show me |
|---|---|---|
| Open commitments: what we promised and what they promised | | |
| Summary of the last conversation | | |
| The client's goals and progress against them | | |
| Deal stage and next step (sales) | | |
| Recent emails with these people | | |
| Company and industry news | | |
| The person's recent changes (new role, promotion, LinkedIn posts) | | |
| Suggested questions to ask | | |
| Who else is involved (sponsor, HR, decision makers) | | |
| Risks and red flags (missed sessions, low scores, silence) | | |
| Personal touches (things they've mentioned: family, travel, interests) | | |
| Logistics (link, time zone, what to send before) | | |

### B3. How I want it
1. Length: ☐ 5 bullets ☐ one page ☐ detailed
2. When: ☐ the evening before ☐ 7 AM the same day ☐ 30 minutes before
3. Where: ☐ private prep event on my calendar ☐ email to me ☐ Google Doc link
4. Style: ☐ plain bullets ☐ short sentences ☐ a table

### B4. Make it mine
1. What do you wish you always remembered before a call?
2. Is there a question you ask in almost every call?
3. What makes a call go well for you?
4. What's one thing a brief should **never** do? (Too long, too generic, repeats what I know…)
5. Anything different for one call type? (For example: "for sales calls, always include their LinkedIn headline.")
6. Paste or attach one brief you think is great.

## Part C · Let Claude interview you (copy and paste)

Paste this into a new Claude chat. Answer one question at a time.

```
You are helping me set up my personal Meeting Prep profile.

Interview me using the questions in Part B (About me, What matters most,
How I want it, Make it mine). Ask ONE question at a time and wait for my
answer. For the ranking question, show me the 12 items as a numbered list
and ask me to pick my top 3 and the 3 I never want to see. If an answer is
vague, ask one short follow-up, then move on.

When we are done, write my profile using exactly these headings:

# Prep Profile – <my first name>
## My role
## My call types
## Top 3 priorities (in order)
## Never show me
## Format (length, timing, where)
## Always remember
## My go-to questions
## Call-type tweaks
## Example of a great brief

Rules for the profile:
- Use my own words where possible.
- Keep it under 400 words, not counting the example brief.
- This profile changes focus and format only. It never changes the team's
  privacy rules.

Then show me the profile and ask if anything should change. When I say it's
right, save it as a Google Doc named "Prep Profile – <my first name>" in my
Drive.
```

The meeting-prep skill reads this profile before every run, so each person's briefs follow their own priorities. Update it after the first week: anything you keep deleting from briefs goes under "Never show me".
