# Build the two homes

Google Drive holds what happened. ClickUp holds what happens next. These folders and sheets don't exist until you run this. One person runs it once.

```
Set up our client folders and sheets for the 5 clients in our Team Settings doc (under "Decisions").

1. In my Google Drive, make a folder named "Team Workspace". Inside it, make a folder named "Clients" with one folder for each client. Inside each client folder: a Doc named "00 Client Summary", and folders named "02 Recaps", "03 Proposals & Contracts", "04 Workbooks & Handouts" and "05 Research".
2. Also inside "Team Workspace", make three folders: "Notes", "Inbox" (with "Transcripts" inside) and "Unsorted".
3. Inside "Team Workspace", make these Google Sheets: Client Map, Contact Log, CRM Check, Client Experience, Nudge Log, Run Log, Score Sheet. Use the column names from the templates folder of the workshop kit (https://github.com/qianquandong/agent-workshop-kit). Leave out the sample rows.
4. Fill in the Client Map: one row for each person at the 5 clients, with a link to the client's folder. Leave private_folder_link empty: each coach fills it in. Fill in what you can find and don't stop to ask; list anything missing at the end.
5. Show me a list of everything you made, with links, and tell me anything you could not do.

If something with the same name already exists, use it and tell me. Don't move, rename, share or delete anything.
```

**Then, by hand:**
- Share **Team Workspace** and the **Team Settings** doc with the whole team (can edit).
- **Each coach:** make a folder "Private – [Client]" in your own Drive, with "Transcripts" and "Coaching Notes" inside, and paste its link into the Client Map (private_folder_link). Nobody else gets access.
- Check the Client Map: every person, the right coach, the renewal date.
- From now on, save meeting notes in the **Notes** folder.
- ClickUp stays as it is. The agents only add tasks, tagged "proposed", using the statuses you already have.
